DATPAQ provides a platform offering a wide range of APIs for developers, agents, and CLI tools. Their services include sample data generation, image processing, profanity detection, human interaction via ping, and IP intelligence. The company emphasizes fast, secure, and scalable API access with transparent pricing and extensive documentation, targeting developers building AI agents and applications.

**Areas:** API · Platform · Data · AI · Developer

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for DATPAQ: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
